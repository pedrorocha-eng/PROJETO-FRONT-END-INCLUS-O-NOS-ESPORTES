Recomendação da equipe

Para a entrega acadêmica, a combinação mais alinhada ao escopo é GitHub Pages (já usado no controle de versão) e, se houver orçamento para nome próprio, um domínio no Registro.br. O site não usa JavaScript nem bibliotecas externas, então não precisa de plano pago de hospedagem nesta etapa.

A escolha também reforça o eixo de sustentabilidade: menos serviços contratados e uma folha de estilo única reduzem transferência de dados.
